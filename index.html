🚀 部署到 GitHub Pages（免費）

1
在 GitHub 建立新 Repository，例如 stock-dashboard
2
把這個 stock-dashboard.html 改名為 index.html 後上傳
3
進入 Repository → Settings → Pages → Source 選 main branch
4
幾分鐘後即可用手機開啟：
vvojox-cloud.github.io/stock-dashboard
✅ 你已經有 GitHub Pages 經驗（凸丕仔笠螺平台），做法完全相同！
