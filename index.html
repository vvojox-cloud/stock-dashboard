📱 手機使用說明

⚠️ 目前你從手機直接開啟 HTML 檔案（file://），所有外部 API 都會被瀏覽器封鎖。
需要把這個檔案放到網路上才能正常使用！

🚀 部署到 GitHub Pages（免費）

1
在 GitHub 建立新 Repository，例如 stock-dashboard
2
把這個 stock-dashboard.html 改名為 index.html 後上傳
3
進入 Repository → Settings → Pages → Source 選 main branch
4
幾分鐘後即可用手機開啟：
vvojox-cloud.github.io/stock-dashboard
✅ 你已經有 GitHub Pages 經驗（凸丕仔笠螺平台），做法完全相同！

💾 資料備份與還原

⚠️ 持股、清單、API Key 都存在「這支裝置的瀏覽器」裡。換手機或清除快取會消失！
換裝置前請先「匯出備份」，到新裝置再「匯入」。
匯出會下載一個 investai-backup.json 檔案，內含你的股票清單與持股成本。傳到新手機後點「匯入備份」選取即可還原。
